Java Overview

  • To start coding with Java, you need to install the Java Development Kit (JDK) and set up your development environment.
  • A JDK contains a compiler, a runtime environment, and various development tools.
  • A compiler translates Java source code into bytecode that can be executed by the Java Virtual Machine (JVM).
  • You will also need an Integrated Development Environment (IDE) to write, debug, and run your Java programs efficiently.
  • In Java to get any code to run you will need a main class
  • You also need a main method within the main class
