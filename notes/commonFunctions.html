Common Functions in Java

  • System.out.print(): Used to print output to the console.
  • System.out.println(): Used to print output to the console on a new line.
  • Math.sqrt(): Used to calculate the square root of a number.
  • String.length(): Used to get the length of a string.
  • Arrays.sort(): Used to sort an array.
  • Scanner.nextLine(): Used to read a line of input from the user.
  • Integer.parseInt(): Used to convert a string to an integer.
  • Double.parseDouble(): Used to convert a string to a double.
