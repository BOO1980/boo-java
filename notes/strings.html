Strings in Java

  • A string in Java is a sequence of characters enclosed in double quotes.
  • Strings are immutable, meaning that once created, they cannot be changed.
  • You can concatenate strings using the + operator.
  • Java provides a String class with various methods for manipulating strings, such as length(), substring(), and toUpperCase().
  • String literals are stored in a common pool, and identical string literals will reference the same memory location.
  • To create a string, you can use the String constructor or simply assign a string literal to a variable.
  • If you type "\n" in a string, it represents a newline character.
